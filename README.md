# 🏠 BuildSmart AI – Home Vision

### Smart Residential Construction Management Platform

BuildSmart AI – Home Vision is a residential construction management platform designed to make construction more transparent, organized and easier to monitor.

The platform connects customers with verified contractors and provides a centralized workflow for project creation, contractor assignment, construction progress monitoring, budget tracking and material management.

## 🚀 Key Features

### 👤 Customer
- Customer registration and login
- Create and manage construction projects
- Add project requirements, location, area and budget
- View assigned contractor
- Track construction progress and milestones
- View daily contractor updates and progress photos
- Monitor budget, expenses and material costs

### 👷 Contractor
- Contractor registration
- Add experience, skills, location and project types
- Resume/portfolio upload
- View assigned projects
- Post daily construction updates
- Upload progress photos
- Track project progress and milestones

### 🛡️ Admin
- Admin dashboard
- Review and verify contractors
- Manage contractor approval status
- Monitor customer projects
- Monitor contractor updates
- Oversee project activity

## 💰 Budget & Material Tracking

The platform provides visibility into:

- Original/target project budget
- Estimated material costs
- Actual material costs
- Labour and other expenses
- Total spending
- Remaining budget

This helps customers monitor project expenses throughout construction.

## 🔐 Security

The application uses:

- Supabase Authentication
- Role-based access
- PostgreSQL database
- Row Level Security (RLS)
- Protected customer/contractor project access
